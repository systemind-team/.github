## Systemind

Systemind is a frontier lab that believes intelligence will scale through networks of agents. Learn more at [systemind.io](https://systemind.io).

### Research

- **[Runtime AI Scientist](https://github.com/systemind-team/Runtime-AI-Scientist)**: official code for the paper [*Can AI Scientists Coordinate at Runtime?*](https://arxiv.org/abs/2610.00980). It applies Runtime Agent Coordination (RAC) to the multi-agent AI scientists ARK, Agent Laboratory, and EvoScientist, evaluated on ResearchClawBench. See the [project page and video](https://systemind-team.github.io/Runtime-AI-Scientist/).
- **[SharedEval](https://github.com/systemind-team/SharedEval)**: a benchmark control plane for evaluating collaboration between agents, with SharedOS as its execution plane.

### Open source

- **[SharedOS](https://github.com/systemind-team/SharedOS)**: a permission-controlled state and delegation kernel with pluggable agent runtimes. See [sharedos.ai](https://www.sharedos.ai).
- **[AICOO Skills](https://github.com/systemind-team/AICOO-Skills)**: an official set of skills to share, maintain, and connect personal AI agents.
- **[aicoo-local-agent](https://github.com/systemind-team/aicoo-local-agent)**: an open protocol and runtime for reaching a live local coding agent (Claude Code or Codex) from another agent. Every tool call is gated on the owner's approval.
